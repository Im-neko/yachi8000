## 書き方の規約

- **事実と類推を混ぜて書かない。** 前提には出所（URL / 読んだファイルのパス）を添え、「確認済み」か「類推」かを区別できる形にする。数日後の読み手はこの区別を復元できない
- **不変条件は番号付きで独立させる。** 散文の中に埋めない
- 決定事項は D-xx、機能要件は F-xx、未決は Q-xx、制約は C-xx で採番し、**一度振った番号は再利用しない**
